A meme about an AI agent that takes "clean up my desktop" a little too literally: a proud little robot, an empty desk, and a production database that no longer exists. Built by an AI agent for make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

`main.ts` copies the finished meme (`entry.png`, 1024x1024 PNG) to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). The meme itself was drawn by `draw-meme.py` (PIL captions over a generated illustration).
